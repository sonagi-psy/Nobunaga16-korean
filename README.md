# NOBU16 PK 한국어 패치

Steam판 **신장의 야망·신생 with 파워업키트(NOBU16 PK)**를 위한 비공식 한국어 패치입니다.

번역 데이터, 한국어 글꼴, UI 이미지 리마스터, 고·저해상도 대응 자산과 안전한 통합 설치기를 포함합니다. 설치기는 원본 파일을 무조건 덮어쓰지 않고, 먼저 Steam 원본의 SHA-256을 검사한 뒤 검증된 파일에만 차등 패치를 적용합니다.

> 이 패치는 KOEI TECMO GAMES의 공식 제품이나 공식 지원물이 아닙니다.

## 주요 기능

- 게임 내 주요 문자열 및 이벤트 대사 한국어화
- 한국어 글꼴과 UI 이미지 리마스터
- 고해상도 및 저해상도용 UI 자산 대응
- Steam 설치 경로 자동 탐색
- 비표준 설치 경로를 위한 **찾아보기** 기능
- 27개 관리 파일의 SHA-256 검증
- 원본 전체 파일을 배포하지 않는 bdiff 차등 패치 방식
- 설치 전 자동 백업 및 설치 실패 시 자동 복원
- 설치 단계, 경과 시간 및 검증 결과를 보여 주는 GUI
- `NOBU16PK 신규 무장 한국어 이름 입력기 v1.5.0` 동봉

```text

```

```text
49D8EAAD1630946539DF7D455FB367B64C50C8DF2F27A2524F571633BE3CBD0F
```

## 설치 방법

1. Steam과 게임을 완전히 종료합니다.
2. 받은 ZIP 파일을 원하는 폴더에 **완전히 압축 해제**합니다.
3. 압축을 푼 폴더에서 `NOBU16_KoreanPatchInstaller.exe`를 실행합니다.
4. 설치기가 게임 경로를 자동으로 찾으면 경로가 맞는지 확인합니다.
5. 게임이 기본 Steam 경로가 아닌 곳에 설치되어 있다면 **찾아보기**를 눌러 `NOBU16.exe`가 있는 게임 폴더를 선택합니다.
6. **Steam 해시 검사**를 실행합니다.
7. 검사 결과를 확인한 뒤 **검증 후 설치**를 누릅니다.
8. 완료 메시지가 나올 때까지 프로그램을 종료하지 마십시오.

설치 중에는 준비, 해시 검사, 패치 생성, 백업, 설치, 사후 검증 및 복원 상태가 화면에 계속 표시됩니다. 파일 크기가 크기 때문에 일부 단계는 시간이 걸릴 수 있습니다.

## 해시 검사 결과

| 상태 | 의미 | 처리 |
| --- | --- | --- |
| `SUPPORTED_STEAM` | 지원하는 정품 Steam 원본과 일치 | 정상 설치 가능 |
| `ALREADY_TARGET` | 이미 목표 패치 파일과 일치 | 재설치가 필요하지 않을 수 있음 |
| `HASH_MISMATCH` | 다른 게임 버전, 다른 모드, 손상 파일 또는 지원하지 않는 원본 | 강력한 경고 후 명시적으로 동의한 경우에만 설치 가능 |
| `MISSING` | 필수 파일이 없음 | 설치 차단 |

### 해시가 일치하지 않는 경우

가장 안전한 방법은 Steam에서 **설치된 파일 무결성 검사**를 실행한 뒤 다시 시도하는 것입니다.

해시가 일치하지 않는 상태에서 강제 설치하면 게임 실행 실패, 문자열 또는 이미지 깨짐, 다른 모드와의 충돌이 발생할 수 있습니다. 설치기는 위험을 명시적으로 확인한 사용자에게만 계속 진행을 허용하지만, 지원하지 않는 원본에 대한 정상 작동은 보장하지 않습니다.

## 삭제 및 복원

설치기는 패치 적용 전에 대상 원본을 별도 백업합니다. 설치 도중 검증이 실패하면 자동 복원을 시도합니다.

문제가 계속되면 Steam의 **설치된 파일 무결성 검사**를 통해 공식 원본으로 복원할 수 있습니다. 별도의 모드나 개인 수정 파일이 있다면 패치 설치 전에 직접 백업하십시오.

## 신규 무장 한국어 이름 입력기

다음 도구가 패키지에 함께 들어 있습니다.

```text

```

통합 설치기의 **이름 입력기 열기** 버튼으로 해당 폴더를 열 수 있습니다. 이름 입력기는 휴대용 보조 도구이며 게임 폴더에 자동으로 복사되지 않습니다. 사용법은 동봉된 `FIRST_TIME_GUIDE_KO.txt`와 `USER_GUIDE_KO.txt`를 확인하십시오.

### 한국어 패치

이 패키지에 포함된 자체 제작 번역, 교정 데이터, 리마스터 자산, 설치기, 패치 제작 스크립트 및 관련 문서의 권리는 패치 제작자에게 있습니다.

별도의 명시적 허가가 없는 한 다음 행위를 허용하지 않습니다.

- 패치 또는 일부 구성요소의 무단 재배포 및 재업로드
- 유료 판매, 후원 보상 등 상업적 이용
- 제작자 표시를 제거한 수정 배포
- 패키지를 다른 프로그램이나 패치에 무단 포함하는 행위

개인적인 비상업적 게임 이용을 위한 다운로드와 설치는 허용됩니다. 별도 배포, 수정 배포 또는 2차 이용이 필요하면 먼저 제작자에게 문의하십시오.

## 글꼴 선택

설치기 첫 화면에서 게임 내 동작·대사 문자열에 사용할 글꼴을 선택할 수 있습니다.

| 글꼴 | 특징 |
| --- | --- |
| 조선궁서체 | 기존 한국어 패치의 기본 글꼴. 고전적이고 붓글씨에 가까운 분위기 |
| 네이버 마루부리 SemiBold | 획이 정돈되어 있으며 긴 문장과 일반 게임플레이 화면에서 읽기 편한 글꼴 |

선택한 글꼴이 처음부터 직접 설치됩니다. 궁서체를 먼저 설치한 뒤 다시 변경하는 방식이 아닙니다.

이미 패치가 설치된 상태에서도 설치기를 다시 실행하면 다른 글꼴로 전환할 수 있습니다.

### 글꼴 변경 범위

글꼴 선택은 다음 항목에 적용됩니다.

- 일반 게임플레이 문자열
- 이벤트 대사
- 설명문 및 알림
- 동작과 명령 관련 문자열

다음 항목은 글꼴 선택에 따라 바뀌지 않을 수 있습니다.

- 이미지에 직접 삽입된 글자
- 별도의 규칙으로 처리되는 인명
- 게임이 독립된 이미지 자산으로 출력하는 일부 UI
